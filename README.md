# Navin Chaudhary — Creative Developer Portfolio

An interactive, editorial-grade creative developer portfolio designed and built for **Navin Chaudhary**. Inspired by the tactile creativity, oversized editorial typography, and kinetic interactions of creative agency design (e.g. gutfeeling.agency), featuring an expressive custom anime character interaction engine, dynamic cursor system, procedural audio synthesizer, and interactive engineering showcase.

---

## 🌟 Key Highlights & Signature Features

### 1. Custom Anime Character Interaction System
- Source: Illustrated character asset pack based on Navin Chaudhary's real identity.
- 12 Addressable Expression States: `idle`, `looking`, `curious`, `happy`, `focused`, `wink`, `surprised`, `confused`, `annoyed`, `angry`, `bored`, `sleeping`.
- Real-time Cursor & Eye Tracking: Calculates pointer vector relative to character center with smooth interpolation, realistic gaze bounds, and subtle 3D head tilt perspective.
- Reactive Personality Logic:
  - First poke/click: Surprised reaction with playful dialogue.
  - Rapid clicks: Escalates through annoyed to anime rage mode with anger vein indicator.
  - Inactivity: Transitions from alert to bored yawns, and eventually sleeping mode.
- Interactive Live Mood Bar: Allows visitors to test each expression dynamically with instant sound effects.

### 2. Custom Graphic Cursor System
- Default: Minimal geometric pointer dot + outer ring.
- Project Hover: Expands smoothly into an editorial pill with "VIEW DETAILS ↗".
- Character Hover: Magnetic callout pill ("POKE NAVIN 👉").
- Playground Hover: "DRAG ✋" indicator.
- Dynamic click ripples and touch device safety fallback.

### 3. Procedural Web Audio Engine
- Built purely on the browser's native **Web Audio API** — zero external MP3 dependencies.
- Subtle UI pops, clicks, hover blips, celebration fanfares, and character emotional vocalizations.
- Integrated sound toggle button in the header with persistent state storage.

### 4. Interactive Sections
- **Section 01 — Hero**: Oversized editorial typography ("NOT JUST WRITING CODE. I BUILD EXPERIENCES."), live character stage, direct social badges, and scroll indicator.
- **Section 02 — Introduction / Manifesto**: "CURIOUS BY NATURE. BUILDER BY CHOICE.", 3 core engineering pillars, verified signature tag.
- **Section 03 — Selected Work**: Flagship projects (*AI SkillPath*, *NexusSync*, *PocketExpense*, *Jarvis AI Assistant*) with architecture metrics, filter tabs, technical challenge/solution breakdown modal, and GitHub links.
- **Section 04 — Expertise**: Real technical stack (React, TypeScript, Node.js, Kotlin, Python, Gemini API, Jetpack Compose, MongoDB, SQL), categorical filtering, and coding-mode character vignette.
- **Section 05 — Experiments / Playground**: Tactile draggable technology stickers with spring physics, confetti celebration triggers, and peeking character easter egg.
- **Section 06 — Journey**: Editorial timeline of verified practical engineering milestones.
- **Section 07 — About Me**: Philosophy, creative flow & music vignette, coffee fuel facts.
- **Section 08 — Contact**: Direct WhatsApp quick-launcher, one-click email copy, verified social profiles, and functional contact form with reactive character watcher.
- **Section 09 — Footer**: Dynamic copyright, back-to-top button, and interactive peeking Navin easter egg.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS (Light editorial agency palette: `#F7F3EA`, `#EFE9DC`, `#171717`, `#F47B35`, `#F5D77E`)
- **Typography**: Space Grotesk, DM Sans, Playfair Display
- **Animations**: Framer Motion
- **Icons**: Pixel-perfect custom brand SVGs + Lucide React
- **Audio**: Web Audio API Synthesizer
- **Particles**: Canvas Confetti
